# AuriX Facebook Launch နှင့် Weekly Content Campaign

Version: MM 1.0  
Primary channel: Facebook  
Conversion channel: Telegram  
Purpose: မတူညီသော audience များကို သီးခြား message ဖြင့် ရောက်ရှိစေပြီး Telegram သို့ ပြောင်းရွှေ့စေခြင်း

## 1. Creative direction lock

### Brand promise

> သုံးမယ့်ဒေတာပမာဏနဲ့ သက်တမ်းကို ကြိုသိနိုင်ပြီး မရှင်းတာရှိရင် လူကိုယ်တိုင် ကူညီပေးမယ့် VPN။

### Viewer memory

ပို့စ်တစ်ပို့စ်ကို မြင်ပြီးနောက် အောက်ပါအချက်တစ်ခုသာ ရှင်းရှင်းလင်းလင်း မှတ်မိစေရမယ်။

> AuriX ကို Telegram ကနေ လွယ်လွယ်ကူကူ စသုံးနိုင်တယ်။ ပမာဏ၊ သက်တမ်းနဲ့ ဈေးနှုန်းကို ကြိုသိနိုင်တယ်။

### Current offer memory

- နေ့စဉ် အခမဲ့ `300 MB` — တစ်ကြိမ်ရယူပြီး `24 နာရီ` အသုံးပြုနိုင်သည်။
- ရက် `30` တိုင်း အခမဲ့ `3 GB` — တစ်ကြိမ်ရယူပြီး `ရက် 30` အသုံးပြုနိုင်သည်။
- `50 GB / ရက် 30 / 3,000 ကျပ်`။
- `100 GB / ရက် 30 / 6,000 ကျပ်`။

“လစဉ် 3 GB” ထက် “ရက် 30 တိုင်း 3 GB” ကို ဦးစားပေးသုံးရမယ်။ Calendar month အစမှာ reset ဖြစ်သည်ဟု မထင်စေရန် ဖြစ်သည်။

### Burmese voice

- ရိုးရိုးပြောသလိုရေးပြီး စာကြောင်းတိုတို သုံးမယ်။
- “အသုံးပြုခွင့်အတိုင်းအတာ” ကဲ့သို့ ရုံးသုံးစကားရှည်များအစား “ဒေတာပမာဏ”၊ “သက်တမ်း”၊ “စသုံး” ဟု ရေးမယ်။
- တစ်ပို့စ်တွင် အဓိကအချက်တစ်ခုသာ ပြောမယ်။
- ကြောက်စိတ်၊ နိုင်ငံရေး၊ hacker ပုံရိပ်နှင့် “အမြန်ဆုံး”၊ “လုံခြုံဆုံး”၊ “အကန့်အသတ်မရှိ” ကဲ့သို့ သက်သေမပြနိုင်သောစကားများ မသုံးရ။
- CTA ကို `Telegram မှာ စသုံးပါ` သို့မဟုတ် `Telegram မှာ မေးပါ` ဟု အခြေအနေအလိုက် သုံးမယ်။

## 3. Launch concept options

အောက်ပါ concept ခြောက်ခုသည် launch post တစ်ခုတည်း၏ alternative များသာ မဟုတ်ပါ။ Launch week အတွင်း audience မတူသူများကို ဆက်တိုက်ဖမ်းရန် အသုံးပြုနိုင်သည့် campaign entry points များဖြစ်သည်။

### L-01 — စသုံးလို့ရပါပြီ

Audience: လူအများနှင့် first-time users  
Role: Master launch announcement  
Format: Static 4:5

ပုံပေါ်စာသား:

> AuriX ကို စသုံးလို့ရပါပြီ။  
> ပမာဏရှင်းရှင်း၊ စတင်ရလွယ်လွယ်။  
> Telegram မှာ စသုံးပါ

Caption:

> VPN သုံးဖို့ ရှုပ်ရှုပ်ထွေးထွေး မလိုပါဘူး။ AuriX မှာ ရမယ့်ဒေတာပမာဏ၊ သုံးလို့ရမယ့်သက်တမ်းနဲ့ ဈေးနှုန်းကို ကြိုသိနိုင်ပါတယ်။ စသုံးချင်ရင် Telegram bot ကိုဖွင့်ပြီး `/start` ကိုနှိပ်ပါ။ မရှင်းတာရှိရင် လူကိုယ်တိုင် ကူညီပေးပါမယ်။

Visual mechanism: ပိတ်နေသော A ပုံစံ gateway ပွင့်လာပြီး cyan signal path တစ်ကြောင်း ဖြတ်သွားသည်။

### L-02 — အရင်စမ်း၊ အဆင်ပြေမှ ရွေး

Audience: ဈေးနှုန်းစဉ်းစားသူနှင့် မယုံကြည်သေးသူ  
Role: Low-risk entry  
Format: Static or 8-second motion

ပုံပေါ်စာသား:

> အရင်စမ်းကြည့်ပါ။  
> နေ့စဉ် 300 MB အခမဲ့  
> Telegram မှာ ရယူပါ

Caption:

> AuriX ကို paid plan မရွေးခင် အရင်စမ်းကြည့်လို့ရပါတယ်။ နေ့စဉ် 300 MB ကို ရယူပြီး 24 နာရီအတွင်း အသုံးပြုနိုင်ပါတယ်။ နောက်တစ်ကြိမ်ရယူနိုင်မယ့်အချိန်ကိုလည်း bot မှာ ပြပေးပါမယ်။

Visual mechanism: A gateway မှ data capsule အသေးတစ်ခု ထွက်လာပြီး ရှင်းလင်းသော start marker ကို ဖြတ်သည်။

### L-03 — အခမဲ့ရွေးချယ်စရာ နှစ်မျိုး

Audience: Free users, students, curious testers  
Role: Explain free ladder without paid-plan clutter  
Format: Two-card static

ပုံပေါ်စာသား:

> အခမဲ့စမ်းဖို့ ၂ မျိုး  
> နေ့စဉ် 300 MB  
> ရက် 30 တိုင်း 3 GB

Caption:

> ခဏခဏ နည်းနည်းသုံးချင်ရင် နေ့စဉ် 300 MB။ ပမာဏပိုလိုပြီး ကြာကြာစမ်းချင်ရင် ရက် 30 တိုင်း 3 GB။ AuriX bot ထဲမှာ ကိုယ်သုံးချင်တာကို ရွေးပြီး ရယူနိုင်ပါတယ်။ ရရှိသည့် key တစ်ခုချင်းစီမှာ သက်တမ်းနှင့် ဒေတာကန့်သတ်ချက် သီးခြားရှိပါတယ်။

Visual mechanism: Gateway တစ်ခုမှ data path နှစ်ကြောင်း ထွက်လာပြီး small/daily နှင့် larger/30-day rhythm ကို ပြသည်။

### L-04 — ကိုယ်နဲ့ကိုက်တာ ရွေး

Audience: Paid-intent users  
Role: Price and plan conversion  
Format: Clean two-card static

ပုံပေါ်စာသား:

> ကိုယ်သုံးသလောက် ရွေးပါ။  
> 50 GB · ရက် 30 · 3,000 ကျပ်  
> 100 GB · ရက် 30 · 6,000 ကျပ်

Caption:

> Plan ရွေးတဲ့အခါ ပမာဏ၊ သက်တမ်းနဲ့ ဈေးနှုန်းကို တစ်နေရာတည်းမှာ ကြည့်နိုင်ပါတယ်။ ပုံမှန်သုံးဖို့ 50 GB၊ ပိုသုံးဖို့ 100 GB ရှိပါတယ်။ Telegram bot မှာ order ဖွင့်ပြီး receipt ပို့ပါ။ ဝန်ထမ်းစစ်ဆေးပြီးမှ access ကို ပေးပါမယ်။

Visual mechanism: နှိုင်းယှဉ်ရလွယ်သော data vessels နှစ်ခု၊ gold selection ring တစ်ခု။

### L-05 — မရှင်းတာရှိရင် မေးလို့ရတယ်

Audience: First-time users, older users, support-sensitive buyers  
Role: Human-support differentiator  
Format: Human-centered static

ပုံပေါ်စာသား:

> မရှင်းတာရှိရင် မေးပါ။  
> Telegram မှာ လူကိုယ်တိုင် ကူညီပေးမယ်။

Caption:

> တပ်ဆင်တာမရတာ၊ key ထည့်တာမသိတာ၊ plan ဘယ်ဟာရွေးရမလဲ မသေချာတာ—Telegram မှာ မေးလို့ရပါတယ်။ Bot က လုပ်ဆောင်ချက်တွေကို အဆင့်လိုက်ပြပေးပြီး လိုအပ်ရင် AuriX ဝန်ထမ်းက ဆက်ကူညီပေးပါမယ်။

Visual mechanism: Phone မှ signal ribbon သည် warm human light ဆီသို့ ဆက်သွားသည်။ Fake chat UI မသုံးရ။

### L-06 — ကြိုသိပြီးမှ သုံး

Audience: Existing VPN users and trust-seekers  
Role: Transparent category positioning  
Format: Static or carousel

ပုံပေါ်စာသား:

> ဒေတာဘယ်လောက်ရမလဲ။  
> ဘယ်လောက်ကြာ သုံးလို့ရမလဲ။  
> AuriX မှာ ကြိုသိနိုင်တယ်။

Caption:

> “Unlimited” ဆိုတဲ့စကားတစ်လုံးထက် ကိုယ်တကယ်ရမယ့် ပမာဏနဲ့ သက်တမ်းက ပိုအရေးကြီးပါတယ်။ AuriX မှာ plan တစ်ခုချင်းစီရဲ့ ဒေတာ၊ သက်တမ်းနဲ့ ဈေးနှုန်းကို မဝယ်ခင် ကြိုပြပါတယ်။ ကိုယ်နဲ့ကိုက်တာကို သိပြီးမှ ရွေးနိုင်ပါတယ်။

Visual mechanism: မြူဖုံးသော လမ်းတစ်ခုနှင့် အစ/အဆုံးမြင်ရသော cyan path တစ်ခုကို နှိုင်းယှဉ်ပြသည်။ Competitor ကို အမည်မတပ်ရ။

### Concept decision

- **Master launch:** `L-01 — စသုံးလို့ရပါပြီ`။ Brand ကို ပထမဆုံးမြင်သူအတွက် အရှင်းဆုံးဖြစ်ပြီး free/paid terms အားလုံးကို ပုံတစ်ပုံထဲ အတင်းမထည့်ရ။
- **Acquisition follow-up:** `L-03 — အခမဲ့ရွေးချယ်စရာ နှစ်မျိုး`။ Paid plan မဝယ်သေးသူကို Telegram claim ဆီ ခေါ်ပေးနိုင်သည်။
- **Conversion follow-up:** `L-04 — ကိုယ်နဲ့ကိုက်တာ ရွေး`။ ဝယ်ယူရန်စိတ်ဝင်စားပြီးသား audience အတွက် ဈေးနှုန်းနှင့် plan ကို တိုက်ရိုက်ပြသည်။
- **Trust retargeting:** `L-05 — မရှင်းတာရှိရင် မေးလို့ရတယ်`။ Post ကြည့်ထားသော်လည်း Telegram မဝင်သေးသူ၏ setup anxiety ကို လျှော့ပေးသည်။

Launch day hero post မှာ offer လေးမျိုးလုံး မထည့်ရန် အကြံပြုသည်။ Hero post ၏အလုပ်မှာ brand ကို မှတ်မိစေပြီး Telegram သို့ ခေါ်ဆောင်ရန်ဖြစ်သည်။ Offer အသေးစိတ်ကို နောက်နေ့ post နှစ်ခုတွင် ခွဲပြမှ mobile ဖတ်ရှုရပိုလွယ်ပြီး audience intent ကိုလည်း တိုင်းတာနိုင်မည်။

## 4. Recommended launch-week sequence

Launch day တွင် offer အားလုံးကို ပို့စ်တစ်ခုထဲ မထည့်ဘဲ အောက်ပါအတိုင်း ဖြန့်မယ်။

| Day | Post | Audience job | Primary metric |
|---:|---|---|---|
| 1 | L-01 စသုံးလို့ရပါပြီ | Brand recognition | Reach, profile visits |
| 2 | L-03 အခမဲ့ရွေးချယ်စရာ နှစ်မျိုး | Free acquisition | Telegram starts, claims |
| 3 | L-05 မရှင်းတာရှိရင် မေးလို့ရတယ် | Reduce setup anxiety | Messages, support starts |
| 5 | L-04 ကိုယ်နဲ့ကိုက်တာ ရွေး | Paid conversion | Orders created |
| 7 | L-06 ကြိုသိပြီးမှ သုံး | Brand trust | Saves, comments, plan views |

အခမဲ့ audience ကို paid post အမြဲမပြဘဲ free → help → clarity → paid ဟူသော ယုံကြည်မှုလမ်းကြောင်းဖြင့် ဆွဲခေါ်မယ်။

## 5. Eight-week Facebook content plan

တစ်ပတ်လျှင် သုံးပို့စ်။ Monday = ရှင်းပြ၊ Wednesday = ကိုယ်နှင့်ဆိုင်သောအခြေအနေ၊ Friday = action/offer ဟူသော rhythm ကို သုံးမယ်။

### Week 1 — AuriX ကို သိစေခြင်း

1. Brand static — `VPN သုံးရတာ မရှုပ်သင့်ဘူး။`
   - Support: `ပမာဏရှင်းရှင်း၊ စတင်ရလွယ်လွယ်။`
   - CTA: `Telegram မှာ စသုံးပါ`
2. Carousel — `AuriX ကို ဘယ်လိုစမလဲ။`
   - Card 1: `Telegram bot ကို ဖွင့်ပါ`
   - Card 2: `အခမဲ့ သို့မဟုတ် paid plan ရွေးပါ`
   - Card 3: `ရရှိတဲ့ key ကို app ထဲထည့်ပါ`
   - Card 4: `မရရင် Telegram မှာ မေးပါ`
3. Offer static — `အခမဲ့စမ်းဖို့ ၂ မျိုးရှိတယ်။`
   - Support: `နေ့စဉ် 300 MB · ရက် 30 တိုင်း 3 GB`

### Week 2 — VPN ပထမဆုံးသုံးသူ

4. FAQ static — `Key ဆိုတာ ဘာလဲ။`
   - Answer: `VPN app ထဲထည့်ပြီး ချိတ်ဆက်ဖို့ AuriX က ပေးတဲ့ access link ပါ။`
5. How-to carousel — `Key ရပြီးရင် ဘာလုပ်ရမလဲ။`
   - Setup အဆင့်များကို live device test ပြီးမှ OS အလိုက်ရေးရန်။
6. Support static — `တပ်ဆင်တာ မရဘူးလား။`
   - Support: `Screenshot နဲ့အတူ Telegram မှာ မေးပါ။`

### Week 3 — ဈေးနှုန်းစဉ်းစားသူနှင့် ကျောင်းသား

7. Value static — `အရင်စမ်း၊ အဆင်ပြေမှ ရွေး။`
   - Offer: `နေ့စဉ် 300 MB အခမဲ့`
8. Planning carousel — `ဒေတာကို ဘယ်လိုရွေးမလဲ။`
   - Card 1: `ခဏခဏ နည်းနည်းသုံးမယ်`
   - Card 2: `ရက်ရှည် ပိုသုံးမယ်`
   - Card 3: `ပမာဏကို ကြည့်ပြီးရွေးမယ်`
   - Usage examples ကို measurement မရှိဘဲ “X hours of video” ဟု မပြောရ။
9. Price static — `3,000 ကျပ်နဲ့ 50 GB`
   - Support: `ရက် 30 အသုံးပြုနိုင်သည်`
   - CTA: `Telegram မှာ Plan ကြည့်ပါ`

### Week 4 — Freelancer နှင့် remote worker

10. Clarity static — `အလုပ်မစခင် သက်တမ်းကို ကြိုကြည့်။`
    - Support: `Plan တစ်ခုချင်းစီမှာ ပမာဏနဲ့ သက်တမ်းကို ပြထားတယ်။`
11. Support scenario — `အရေးကြီးတဲ့အချိန် မရှင်းတာရှိရင်?`
    - Support: `Telegram မှာ လူကိုယ်တိုင် မေးလို့ရတယ်။`
12. Plan static — `ပိုသုံးဖို့ 100 GB`
    - Offer: `ရက် 30 · 6,000 ကျပ်`
    - “work-ready,” “stable,” “always on” ဟု live evidence မရှိဘဲ မရေးရ။

### Week 5 — Video နှင့် social အသုံးများသူ

13. Education static — `ကြည့်တာများလေ၊ ဒေတာပိုသုံးလေ။`
    - Support: `ကိုယ့်ဒေတာကျန်တာကို မကြာခဏ စစ်ပါ။`
14. FAQ carousel — `ဒေတာကုန်ရင် ဘာဖြစ်မလဲ။`
    - Card 1: `သတ်မှတ်ပမာဏပြည့်ရင် key ကို ပိတ်မယ်`
    - Card 2: `လိုအပ်ရင် plan အသစ်ရွေးနိုင်တယ်`
    - Card 3: `Telegram မှာ ဆက်မေးနိုင်တယ်`
15. Comparison static — `50 GB လား၊ 100 GB လား။`
    - Support: `ကိုယ်သုံးမယ့်ပမာဏနဲ့ ကိုက်တာကိုရွေးပါ။`

### Week 6 — ယုံကြည်မှုနှင့် payment clarity

16. Payment static — `Receipt ပို့ပြီးရင် ချက်ချင်းမဖွင့်သေးပါ။`
    - Support: `AuriX ဝန်ထမ်းစစ်ဆေးပြီးမှ access ပေးပါတယ်။`

    - Card 4: `အတည်ပြုပြီးရင် access ရပါမယ်`

    - CTA: `လုပ်ဆောင်ပုံကို Telegram မှာ ကြည့်ပါ`

### Week 7 — Devices နှင့် shared data

## 7. Caption formula

Facebook caption တစ်ခုကို အောက်ပါအတိုင်း တည်ဆောက်မယ်။

1. Audience ၏ အခြေအနေကို စာကြောင်းတစ်ကြောင်းဖြင့် ဖမ်းမယ်။
2. AuriX fact တစ်ခုသာ ရှင်းပြမယ်။
3. လုပ်ဆောင်ရမည့် next step တစ်ခု ပေးမယ်။
4. လိုအပ်ပါက သက်တမ်း၊ eligibility သို့မဟုတ် availability line ထည့်မယ်။

Template:

> `[အခြေအနေ/မေးခွန်း]`  
> `[AuriX fact တစ်ခု]`  
> `[Telegram CTA]`  
> `[လိုအပ်သော terms]`

Hashtag ကို နှစ်ခုမှ လေးခုအထိသာသုံးရန်:

> `#AuriX #VPNMyanmar #TelegramBot #MyanmarTech`

## 8. Visual and format rotation

တစ်မျိုးတည်းသော gateway ပုံကို အမြဲမသုံးဘဲ brand motifs ကို အောက်ပါအတိုင်း လှည့်သုံးမယ်။

| Content type | Visual object | Best format |
|---|---|---|
| Brand | A-shaped gateway + signal path | Static/motion |
| Free offer | Small data capsule or two paths | Static |
| Paid plan | Measured data vessel/cards | Static/carousel |
| Support | Phone + warm human light | Static |
| Education | Shared reservoir/clear markers | Carousel |
| Payment | Receipt card under review light | Carousel |
| Operations | Gateway with amber service marker | Static/story |
| Testimonial | Real user setting with consent | Photo/static |

Feed တစ်တန်းတွင် offer card သုံးပို့စ်ဆက်မတင်ရ။ Offer → human/help → education ဟု visual rhythm ပြောင်းပေးရမယ်။

## 9. Claims and publication gate

Repository code တွင် offer ladder အားလုံးကို ထည့်ထားသော်လည်း public post မထုတ်မီ production environment တွင် အောက်ပါအချက်များကို စစ်ရမယ်။

- `/claim` မှ 300 MB key ထုတ်ပေးပြီး 24 နာရီနောက် ထပ်ရယူနိုင်မှု မှန်ကန်ခြင်း။
- `/trial` မှ 3 GB key ထုတ်ပေးပြီး ရက် 30 နောက် ထပ်ရယူနိုင်မှု မှန်ကန်ခြင်း။
- 50 GB နှင့် 100 GB order, receipt review, approval, provisioning နှင့် expiry flow အလုပ်လုပ်ခြင်း။
- Telegram support တာဝန်ယူသူနှင့် response hours ကို သတ်မှတ်ထားခြင်း။
- Live server capacity နှင့် quota enforcement ကို acceptance test လုပ်ထားခြင်း။

Speed, latency, app compatibility, streaming access သို့မဟုတ် security level အကြောင်း claim များကို တိုင်းတာချက်နှင့် test context မရှိဘဲ မရေးရ။

## 10. Measurement loop

Audience angle တစ်ခုချင်းစီကို impressions ဖြင့်သာ မဆုံးဖြတ်ရ။

| Post goal | Primary measure |
|---|---|
| Brand recognition | Reach, profile visits, follows |
| Free acquisition | Telegram starts, successful claims |
| Education | Saves, shares, qualified comments |
| Support trust | Telegram questions, resolved setup cases |
| Paid conversion | Orders created, verified receipts, approved subscriptions |
| Retention | Renewals, repeat claims, support recontacts |

နှစ်ပတ်တစ်ကြိမ် hook၊ audience နှင့် CTA ကို နှိုင်းယှဉ်ပြီး အားနည်းဆုံးအပိုင်းတစ်ခုသာ ပြင်ရမယ်။ ပို့စ်တစ်ပို့စ်မအောင်မြင်တိုင်း brand style အားလုံးကို တစ်ပြိုင်နက် မပြောင်းရ။

## 11. Language approval

ဤ document သည် ပိုသဘာဝကျသော Burmese working copy ဖြစ်သော်လည်း paid campaign မစမီ Myanmar native copy reviewer တစ်ဦးက အောက်ပါအချက်များကို နောက်ဆုံးစစ်ရမယ်။

- ဒေသအလိုက် မသဘာဝဖြစ်နိုင်သော စကားလုံးများ။
- `နေ့စဉ်`၊ `24 နာရီ`၊ `ရက် 30 တိုင်း` ဟူသော terms ကို audience နားလည်ပုံ။
- Payment နှင့် support စာသားက live process နှင့် ကိုက်ညီမှု။
- Facebook ပုံပေါ်စာသားတွင် font shaping နှင့် line break မှန်ကန်မှု။
