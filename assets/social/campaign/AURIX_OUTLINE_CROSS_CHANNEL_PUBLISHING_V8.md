# AuriX × Outline cross-channel publishing V8

## Product statement

AuriX independently provides Outline-compatible access keys. Customers use those keys in the official Outline Client. AuriX is not presented as an official Outline Foundation partner.

The simplest customer explanation is:

> AuriX က access key ပေးပါတယ်။ အဲဒီ key ကို official Outline Client ထဲထည့်ပြီး VPN ချိတ်ဆက်သုံးရပါတယ်။

## Asset sequence

| Order | Post | Audience job |
|---|---|---|
| 1 | Guide overview | Explain app + key before any platform detail |
| 2 | Android | Google Play and Android setup |
| 3 | iPhone/iPad | App Store and iOS setup |
| 4 | Windows | Official desktop installer and setup |
| 5 | macOS | Mac App Store and setup |
| 6 | Linux | Official repository / Debian package path |
| 7 | ChromeOS | Google Play Android client on supported Chromebooks |

The three retention posts can run between guide posts: connection help, allowance check, and expiry check.

## Channel use

### Facebook Page

Publish the 1080 × 1350 PNG with its matching TXT caption. Keep official download links and the AuriX bot link in the caption; do not draw them as buttons in the artwork.

### Telegram public channel

Use the same PNG/TXT pair. Pin the overview post, then publish one platform guide at a time so subscribers can forward the relevant post.

### Telegram community group

Use each guide as a reusable answer. Ask the member which device they use, then reply with that platform's PNG and caption. Never ask members to paste complete access keys publicly.

### Telegram bot

Use the overview asset after first claim/purchase, then deliver the matching platform asset when the user selects Android, iPhone/iPad, Windows, macOS, Linux, or ChromeOS. The bot remains the source for AuriX keys, Usage, and Status; the official Outline Client remains the connection app.

## Official requirements used

- Android 10+
- iOS 15.5+
- Windows 10+
- macOS 12+
- Linux: Ubuntu 20.04+; official current path targets Debian-based distributions
- ChromeOS: official Android client through Google Play on supported Chromebooks

Always keep links to official Outline download locations in captions. Do not redistribute installer files through AuriX social or Telegram posts.
