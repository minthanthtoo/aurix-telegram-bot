# Gemini Plan Council

Model: `ag/gemini-3.7-flash-high` via the user-provided external 9Router endpoint.

The council approved the launch-plus-giveaway mechanism but identified the main strategic risk: making `100GBFREE` the only message would attract free-only traffic and hide the product. It recommended clarifying the product as a 30-day Outline VPN key, replacing the casual `အရင်ရောက်သူ ၅ ယောက်` with `ပထမဆုံး ၅ ဦး`, and using the direct action `Bot တွင် 100GBFREE ဟု ပို့ပါ`.

Adopted:

- Product appears directly below the keyword.
- Scarcity uses `ပထမဆုံး ၅ ဦး`.
- Duration uses `သက်တမ်း ၃၀ ရက်`.
- The exact keyword is repeated only in the action line where typing accuracy matters.

Human localization adjustment:

- `Bot တွင် ... ဟု ပို့ပါ` was judged grammatically correct but formal for the target feed. The final social voice uses `Bot ထဲမှာ 100GBFREE လို့ ပို့လိုက်ပါ`, which is shorter, natural in Myanmar social commerce, and still exact about the action.
