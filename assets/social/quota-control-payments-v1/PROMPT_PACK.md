## Usage contract

- Use the element prompts only for independent, text-free visual components.
- Use the compositor prompt with supplied official brand and payment assets.
- Use the master prompt when a capable multimodal design model must attempt the whole creative in one shot.
- Burmese text, exact thresholds, wallet names, logos, and handles should be applied deterministically whenever the production environment permits.
- Verified warning levels are `25%`, `10%`, and `5%`. Do not substitute `50%`, `10%`, and `0%` unless the product implementation changes.
