## Treatment rules

- Preserve each icon's native artwork, colors, and proportions.
- Show deterministic text labels beside or below the icons at small sizes.
- Do not recolor, redraw, merge, or ask an image model to imitate these marks.
- Do not call the wallets AuriX partners unless a partnership is separately documented.
- Prefer the current app icon set for a compact, equally recognizable five-method rail; use full horizontal marks only when official brand kits are supplied.
