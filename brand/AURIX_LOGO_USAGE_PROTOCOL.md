# AuriX Logo-Use Protocol

This file is the required preflight for every AuriX social graphic, cover, avatar, motion frame, presentation, or external handoff.

## Canonical assets

Do not infer approval from a version number. Read `brand/README.md` and use only the documented masters:

- primary mark: `brand/v2/aurix-logo-mark-v2.svg`;
- horizontal light-background lockup: `brand/v2/aurix-logo-horizontal-v2.svg`;
- horizontal dark-background lockup: `brand/v2/aurix-logo-horizontal-reverse-v2.svg`;
- Facebook profile: `brand/v2/aurix-profile-facebook-clean.svg`;
- Facebook cover: `brand/v3/facebook-cover-mobile-safe-v3.svg`;
- Telegram Bot, Group and Channel: the corresponding V4 SVG masters.

Root-level V1 files are design history. V5–V7 Telegram avatars are experiments unless a later approval document explicitly promotes them.

## Role hierarchy

Assign each mark a role before composition:

1. **AuriX** — primary seller/service brand.
2. **AuriX Bot avatar** — action path or product interface.
3. **Outline** — secondary technology-recognition anchor.
4. **Wallet marks** — tertiary payment reassurance.

Outline, Telegram and payment marks must not appear visually stronger than AuriX. Do not imply an official partnership through equal logo scale, shared lockups, or decorative co-brand framing.

## Responsive use

- Use the horizontal lockup only when the wordmark is comfortably readable.
- At small sizes, omit the tagline by using a deliberately prepared compact lockup; never crop the tagline accidentally.
- Use the mark alone for profile images and compact brand stamps.
- Keep clear space equal to the width of the X signal.
- Do not add a second decorative tile around an icon that already has a container.
- Use only one external boundary around Telegram avatars.

## Required validation

Inspect every composition at:

- full production size;
- 324 × 405 feed preview for a 1080 × 1350 post;
- approximately 48 px for recognition.

Reject the composition when:

- viewers are likely to remember Outline but not AuriX;
- more than one AuriX geometry appears;
- an experimental asset is mixed with an approved master;
- tagline or badge details become illegible;
- the Bot modifier overwhelms the AuriX mark;
- logo containers or shadows create a false co-brand relationship.

Record every selected asset path in the campaign plan and manifest.
